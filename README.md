# E-Commerce Profit Intelligence Dashboard 📊

## Overview
This project is an advanced Power BI Dashboard built to analyze and visualize key business metrics for an E-Commerce platform.

The dashboard provides deep insights into:
- Sales Performance
- Customer Behavior
- Profit Analysis
- Shipping Costs
- Regional Performance
- Customer Profitability

using interactive visualizations and KPIs.

---

## 🚀 Features

- Sales & Profit Analysis
- Customer Segmentation
- Region Wise Revenue Tracking
- Product Category Performance
- Shipping Cost vs Profit Analysis
- Payment Method Insights
- Seasonal Sales Trends
- Customer Profitability Analysis
- Repeat Customer Tracking
- Interactive Filters & Drilldowns

## 📈 Key Insights

- Electronics category generated the highest revenue.
- North America recorded the highest sales quantity.
- Female customers contributed slightly higher profit than male customers.
- Spring season showed the highest sales contribution.
- Debit Card and PayPal were the most used payment methods.
- VIP customers generated higher profit margins despite lower customer count.
